🍔 TastyGo – Online Food Ordering System

TastyGo is a web-based food ordering system that allows users to browse food items, add them to their cart, and place orders online.

🚀 Features

- User Registration and Login
- Browse Food Menu
- Add to Cart and Remove Items
- Checkout System
- Order Management
- User Order History
- Admin Dashboard
- Add, Edit and Delete Food Items
- Category Management

🛠️ Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP

🌐 Live Demo

"Visit TastyGo" (https://tastygofood.42web.io/TastyGo/)

⚙️ Installation

1. Download this repository.
2. Install XAMPP.
3. Copy the project folder into the "htdocs" directory.
4. Start Apache and MySQL.
5. Create the database using phpMyAdmin.
6. Import the project database.
7. Configure the database connection.
8. Run the project using XAMPP.
